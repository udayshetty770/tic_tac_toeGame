# 🎮 Tic Tac Toe Game in C#

A fully functional console-based Tic Tac Toe game built in C#. Play against the computer in a classic 3x3 grid battle of X vs O.

## 🚀 Features

- 3x3 grid using a 2D string array
- Player vs Computer gameplay
- Randomized computer moves
- Win/draw detection after each turn
- Clean console UI with board updates

## 🧠 How It Works

- Player always plays as **X**
- Computer plays as **O**
- After each move, the game checks for a winner or draw
- Game ends when someone wins or the board is full

## 🛠️ Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/tic-tac-toe-csharp.git
   ```

2. Open the project in Visual Studio or any C# IDE

3. Run the program:
   ```bash
   dotnet run
   ```

## 🎯 Gameplay

- Enter your move as two numbers: `row column` (e.g., `1 2`)
- The computer will respond with a random valid move
- The board updates after each turn
- Win messages or draw messages are displayed at the end

## 📦 Technologies Used

- C#
- .NET Console Application
- 2D Arrays
- Random Number Generator
